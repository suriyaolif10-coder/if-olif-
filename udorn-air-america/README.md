# ฐานบินอุดร กับ แอร์อเมริกา — วิดีโออธิบายแบบแอนิเมชัน (HTML/CSS/JS)

วิดีโอแนวตั้ง 1080×1920, 30 FPS, 90 วินาที, 9 ฉาก ลายเส้นการ์ตูนประวัติศาสตร์ (เส้นหมึกหนา สีสด แรเงาแบบเซล)
ทุกภาพวาดสดด้วย Canvas 2D และเป็นฟังก์ชันของเวลา จึงเลื่อนไปเวลาไหนก็ได้ตรงเฟรม

> ภาพทั้งหมดเป็น **ภาพวาดประกอบจำลอง** ไม่ใช่ภาพถ่ายหรือฟุตเทจจากเหตุการณ์จริง และในวิดีโอมีป้ายบอกไว้ทุกฉาก

## เปิดใช้งาน
```bash
cd udorn-air-america
python3 -m http.server 8000      # แล้วเปิด http://localhost:8000
```
ดับเบิลคลิก `index.html` ก็เปิดได้ แต่ถ้าเปิดผ่าน `file://` เบราว์เซอร์จะไม่ยอมส่งเสียงบรรยายจากไฟล์ใน `assets/` เข้าระบบมิกซ์เสียง
ยกเว้นไฟล์ที่โหลดผ่านปุ่ม 🎙 ในตัวเล่น จึงควรเปิดผ่านเว็บเซิร์ฟเวอร์

พารามิเตอร์ใน URL: `?t=42` เริ่มที่วินาทีที่ 42 · `?autoplay=1` เล่นทันที · `?still=1` ซ่อนแถบควบคุม (ไว้แคปภาพ)

## เสียง
| ไฟล์ | หน้าที่ |
|---|---|
| `assets/audio/voiceover.mp3` | เสียงบรรยาย (หรือกด 🎙 / ลากไฟล์มาวาง) ถ้ามีไฟล์นี้ **เสียงบรรยายจะเป็นนาฬิกาหลักของวิดีโอ** |
| `assets/audio/music.mp3` | เพลงประกอบ (ไม่ใส่ก็ได้ จะใช้เพลงสังเคราะห์ในตัว) |
| — | เอฟเฟกต์เสียง (เครื่องยนต์ไอพ่น ใบพัด เฮลิคอปเตอร์ ลม วูบ ตราประทับ ป๊อป) สังเคราะห์ในตัว กำหนดจังหวะใน `sfx` ของแต่ละฉาก |

ระบบให้ **เสียงบรรยายดังกว่าเสียงอื่นเสมอ**: ระหว่างที่มีบรรทัดบรรยาย เพลงจะเบาลงเหลือประมาณ 30% เอฟเฟกต์เหลือประมาณ 45% และมีคอมเพรสเซอร์คุมที่ปลายทางเสียงรวม
ปรับระดับเสียงแต่ละชั้นได้ที่ ⚙

## ซับไตเติลตรงกับเสียงพูดทีละคำ
- ข้อความบรรยายอยู่ใน `js/narration.js` บรรทัดละช่วงเวลา (`start`/`end`) ใส่ `[วงเล็บเหลี่ยม]` รอบคำที่ต้องการให้เป็น**สีเหลือง**
- **ถ้าไม่มีเวลาของแต่ละคำ:** ตัวเล่นจะตัดคำภาษาไทยด้วย `Intl.Segmenter` แล้วแบ่งเวลาตามความยาวคำ
- **ถ้าต้องการให้ตรงทีละคำจริง** (เลือกทางใดทางหนึ่ง):
  1. **📝 นำเข้า JSON เวลาของคำ** จาก Whisper / WhisperX / ElevenLabs ได้ทั้งรูปแบบ `[{word,start,end}]`, `{words:[...]}` และ `{segments:[{words:[...]}]}`
  2. ใส่ `words: [["คำ", เริ่ม, จบ], ...]` ในบรรทัดนั้นเอง
  3. **⏱ โหมดจับเวลา (ปุ่ม T):** เล่นเสียงแล้วกด Enter ตอนเริ่มพูดแต่ละบรรทัด จากนั้นคัดลอกผลไปวางใน `narration.js`
- **ถ้าเสียงจริงยาวไม่ตรงกับ 90 วินาที:** ปรับ `dur` ของฉากใน `js/scenes.js` ให้ตรงกับเวลาบรรยาย

## โครงสร้าง (แก้ไขได้ทุกส่วน)
```
index.html          ตัวเล่นแนวตั้งเต็มจอ ปรับขนาดตามหน้าจอ
css/style.css       หน้าตาตัวเล่น (ล็อกสัดส่วน 9:16 ให้พอดีหน้าจอ รองรับมือถือ)
js/engine.js        ชุดเครื่องมือวาด: เส้นหมึก + แรเงาเซล, กล้อง, พารัลแลกซ์, ภูเขา/ป่า/เมฆ/ฝุ่น/ควัน, ข้อความ, ตราประทับ, เกรนกระดาษ
js/assets.js        ตัวละคร 4 ตัว (ชุดและสัดส่วนเดิมทุกฉาก), เครื่องบิน/เฮลิคอปเตอร์ยุค 1960, แผนที่
js/narration.js     บทบรรยาย + เวลา (แก้ตรงนี้)
js/scenes.js        ไทม์ไลน์ 9 ฉาก, การเปลี่ยนฉาก, จังหวะเอฟเฟกต์เสียง (แก้ตรงนี้)
js/subtitles.js     ซับไตเติลทีละคำ (ตัวขาว ขอบดำ คำสำคัญสีเหลือง)
js/audio.js         มิกซ์เสียงบรรยาย/เพลง/เอฟเฟกต์ + ลดเสียงเพลงขณะมีบรรยาย
js/player.js        นาฬิกา 30 FPS, การเปลี่ยนฉาก (fade/slash/iris/ink/panel), ปุ่มควบคุม, บันทึก WebM
fonts/              Kanit (SIL Open Font License)
```

**ตัวละคร** (กำหนดสีไว้ที่ `PAL` ใน `assets.js`)
- ช่างภาคพื้นดินกองทัพอากาศสหรัฐฯ: ชุดปฏิบัติงานสีเขียวมะกอก หมวกแก๊ป
- นักบินแอร์อเมริกา: เสื้อเชิ้ตพลเรือนแขนสั้น กางเกงกากี แว่นกันแดด
- ช่างเครื่องชาวไทย: ชุดหมีสีน้ำเงิน ผ้าขนหนูคล้องคอ
- นักบินสหรัฐฯ ที่ถูกยิงตก: ชุดบินสีเขียว หมวกบินสีขาว

**อากาศยาน**
- F-4 / RF-4C Phantom II (ลายพรางแบบที่ใช้ในเอเชียตะวันออกเฉียงใต้)
- Pilatus PC-6 Porter
- Fairchild C-123 Provider
- Sikorsky H-34
- Bell UH-1 "Huey"

**ท่าทาง:** `idle wave marshal point talk clip wrench` และเดินได้ (`walk:true`) มีพูดขยับปาก (`talk:true`) กะพริบตา และเส้นสั่นแบบการ์ตูนมือวาด

## ส่งออกเป็นวิดีโอ
- **⏺ บันทึกวิดีโอ (WebM):** ใช้ได้ใน Chrome/Edge บันทึกตามเวลาจริง 90 วินาที ได้ทั้งภาพและเสียงที่มิกซ์แล้ว
- **ถ้าต้องการ MP4 คุณภาพสูงแบบตรงทุกเฟรม:** ใช้ Playwright เรียก `window.renderAt(t)` ทีละเฟรม (t = n/30) เก็บภาพ PNG แล้วรวมกับไฟล์เสียงด้วย ffmpeg

## ข้อเท็จจริงที่ใช้ในบท (ควรตรวจกับแหล่งอ้างอิงก่อนเผยแพร่)
- **ฐานบินอุดร (Udorn RTAFB):** สหรัฐฯ ใช้ในช่วงสงครามเวียดนามตามความตกลงกับรัฐบาลไทย กองบินลาดตระเวนทางยุทธวิธีที่ 432 ประจำที่นี่ตั้งแต่ปี 2509 (1966) ใช้ RF-4C และ F-4
- **ฐานบินอื่นในไทยที่สหรัฐฯ ใช้ในยุคนั้น:** ตาคลี โคราช อุบลฯ นครพนม อู่ตะเภา
- **แอร์อเมริกา:** สายการบินที่ซีไอเอเป็นเจ้าของอย่างลับ ๆ มีฐานปฏิบัติการสำคัญที่อุดร บินในลาวด้วยเครื่องบินขึ้นลงระยะสั้น (เช่น Porter) ใช้ C-123 และเฮลิคอปเตอร์ H-34 กับ Huey ทำงานขนส่ง ทิ้งเสบียงทางอากาศ และค้นหาช่วยเหลือ
- **ไลมาไซต์ (Lima Site):** ลานบินขนาดเล็กในลาว ล่องแจ้ง (LS 20A) เป็นฐานหลักของกองกำลังม้งที่ซีไอเอสนับสนุนใน "สงครามลับ"
- **ช่วงปิดฉาก:**
  - ข้อตกลงหยุดยิงในลาว ปี 2516 (1973)
  - แอร์อเมริกาหยุดบินในลาว ปี 2517 (1974)
  - ทหารสหรัฐฯ ถอนออกจากไทย ปี 2519 (1976)
- **ปัจจุบัน:** กองบิน 23 กองทัพอากาศไทย ใช้ทางวิ่งร่วมกับท่าอากาศยานนานาชาติอุดรธานี

**สิ่งที่เป็นภาพประกอบ ไม่ใช่ข้อมูลจริง**
- ลูกศรในฉากที่ 2
- ตำแหน่งจุด LS และเส้นทางบินในฉากที่ 7
- โครงร่างแผนที่ ซึ่งเป็นแบบประมาณ

ทั้งหมดนี้มีข้อความกำกับไว้ในวิดีโอแล้ว
