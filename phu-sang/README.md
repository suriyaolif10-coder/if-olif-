# WHAT IF HISTORY: ภูซาง หนองบัวลำภู — วิดีโอการ์ตูนประวัติศาสตร์ (HTML/CSS/JS)

วิดีโอแนวตั้ง 1080×1920, 30 FPS, 9 ฉาก ยาวประมาณ 90 วินาที (ยาวตามเสียงบรรยายจริง)
ลายเส้นคอมิกประวัติศาสตร์ เส้นหมึกหนา แรเงาแบบเซล ฉากชนบทอีสานยุค 2500–2510 ทุกภาพวาดสดด้วย Canvas และเลื่อนไปเวลาไหนก็ได้ตรงเฟรม

## เปิดใช้งาน
```bash
cd phu-sang
python3 -m http.server 8000      # แล้วเปิด http://localhost:8000
```
พารามิเตอร์ใน URL: `?t=40` เริ่มที่วินาทีที่ 40 · `?autoplay=1` เล่นทันที · `?still=1` ซ่อนแถบควบคุม (ไว้แคปภาพ)

## เสียง
| ไฟล์ | หน้าที่ |
|---|---|
| `assets/audio/voiceover.mp3` | เสียงบรรยายจาก Google AI Studio (หรือกด 🎙 / ลากไฟล์มาวาง) — ใช้เป็นนาฬิกาหลักของวิดีโอ |
| `assets/audio/music.mp3` | เพลงประกอบ (ไม่ใส่ก็ได้ จะใช้เพลงแนวสารคดีลุ้นระทึกที่สังเคราะห์ในตัว) |
| — | เสียงบรรยากาศ สังเคราะห์ในตัว: ลม นก แมลงกลางป่า เสียงเท้า วิทยุเก่า นาฬิกา เครื่องยนต์รถบรรทุก เสียงขุดดิน เสียงกระดาษ |

ปรับระดับเสียงบรรยาย เพลง และเสียงบรรยากาศแยกกันได้ที่ ⚙
ระหว่างที่มีเสียงพูด เพลงจะเบาลงเหลือประมาณ 30% และเสียงบรรยากาศเหลือประมาณ 45% **เสียงบรรยายจึงดังกว่าเสียงอื่นเสมอ**

## ทำให้ฉากและซับไตเติลตรงกับเสียงจริง
เวลาใน `js/narration.js` ตอนนี้เป็น**เวลาประมาณ**ตามแผน 90 วินาที เมื่อได้ไฟล์เสียงจริงแล้ว:
1. วางไฟล์ไว้ที่ `assets/audio/voiceover.mp3`
2. กด **T** (โหมดจับเวลา) แล้วเล่นเสียง กด **Enter** ตอนเริ่มพูดแต่ละย่อหน้า **ความยาวของทุกฉากจะขยับตามเสียงทันที** แล้วคัดลอกผลไปวางใน `narration.js`
   - หรือนำเข้าไฟล์ JSON เวลาของคำ (📝) ถ้าต้องการให้ตรงทีละคำ
3. ฉากจะตัดตรงกลางช่วงเงียบระหว่างย่อหน้า ฉากสุดท้ายเก็บไว้อีกประมาณ 4 วินาทีสำหรับหน้าปิด

ข้อความซับไตเติลคือ**บทบรรยายที่ให้มาคำต่อคำ** ไม่เพิ่มคำใหม่ ไม่ตัดคำออก วงเล็บเหลี่ยม `[ ]` ใช้กำหนดคำที่แสดงเป็นสีเหลืองเท่านั้น

## ภาพถ่ายจริง (เปลี่ยนแหล่งภาพได้)
วิดีโอใช้ภาพวาดทั้งหมด และมีป้าย "ภาพวาดจำลอง · ไม่ใช่ภาพถ่ายจริง" ติดอยู่ทุกฉาก
ถ้ามีภาพถ่ายจริง ให้วางไฟล์ไว้ใน `assets/images/` แล้วกรอก `src` และ `credit` ใน `js/images.js`:

| ช่องภาพ | ฉาก | ชนิด |
|---|---|---|
| `s3_archive` | 3 | ภาพจดหมายเหตุ |
| `s5_archive` | 5 | ภาพจดหมายเหตุ |
| `s8_stupa` | 8 | ภาพถ่ายปัจจุบัน — สถูป |
| `s8_museum` | 8 | ภาพถ่ายปัจจุบัน — พิพิธภัณฑ์ |

ภาพจริงจะแสดงในกรอบรูปถ่าย มีแถบสีแดงระบุว่า **"ภาพถ่ายจดหมายเหตุ (ภาพจริง)"** หรือ **"ภาพถ่ายจริง (ปัจจุบัน)"** พร้อมบรรทัดแหล่งที่มา จึงไม่ปนกับภาพวาด
ช่องที่ไม่มีภาพจะแสดงเฉพาะภาพวาด ควรใช้เฉพาะภาพที่มีสิทธิ์เผยแพร่

## ความถูกต้องทางประวัติศาสตร์
- ข้อความบนจอใช้เฉพาะข้อมูลที่อยู่ในบท:
  - พ.ศ. 2500–2510
  - ถนนอุดรธานี–หนองบัวลำภู พ.ศ. 2504
  - เหตุการณ์ที่สถานีตำรวจหนองบัวลำภู พ.ศ. 2509 มีผู้เสียชีวิต 2 คน
  - การขยายตัว พ.ศ. 2515–2518 และมาตรการของรัฐ
  - สถูปและพิพิธภัณฑ์ในปัจจุบัน
- **ไม่มีการแต่งชื่อบุคคล คำพูด หรือพาดหัวข่าว** หนังสือพิมพ์ในภาพเป็นเส้นแทนตัวหนังสือเท่านั้น
- **ตำแหน่งบนแผนที่เป็นแบบประมาณ** เพราะบทไม่ได้ระบุพิกัด ได้แก่ เขตงานภูซาง แนวเทือกเขาภูพาน และขอบเขตที่ขยายตัว ทุกจุดมีข้อความ "โดยประมาณ / ภาพประกอบ" กำกับไว้
- **ฉากเหตุการณ์ปี 2509** แสดงเพียงเงาคนในระยะไกล ไม่มีอาวุธหรือภาพความรุนแรง
- **ฉากปี 2515–2518** แบ่งจอให้ทั้งสองฝ่ายเท่ากัน นำเสนออย่างเป็นกลาง
- **ตัวละครทุกตัวเป็นตัวละครประกอบ** ไม่ได้แทนบุคคลจริง หน้าปิดบอกไว้แล้ว
- วิดีโอนี้ไม่มีส่วนที่เป็นเรื่องสมมติ ("What if") ถ้าตอนต่อไปมี ควรติดป้าย "ประวัติศาสตร์สมมติ" ไว้ตลอดช่วงนั้น
- อ้างอิงเนื้อหา: บทความของเดอะอีสานเรคคอร์ด (theisaanrecord.co) ตามที่ระบุในบท

## โครงสร้างไฟล์
```
index.html, css/style.css   ตัวเล่นแนวตั้ง ปรับขนาดตามหน้าจอ
js/engine.js     ชุดเครื่องมือวาด (เส้นหมึก, แรเงาเซล, กล้อง, ภูเขา/ป่า/เมฆ/หมอก, ข้อความ, เกรนฟิล์ม)
js/assets.js     ตัวละคร 4 แบบ + ฉากประกอบ (บ้านใต้ถุนสูง, รถบรรทุก, สถานีตำรวจ, ที่พักในป่า, สถูป, พิพิธภัณฑ์, วิทยุ, หนังสือพิมพ์) + แผนที่อีสาน
js/images.js     ช่องภาพถ่ายจริง (แก้ไขได้)
js/narration.js  บทบรรยาย + เวลา (แก้ไขได้)
js/scenes.js     9 ฉาก, การเปลี่ยนฉาก, เสียงบรรยากาศ (แก้ไขได้)
js/subtitles.js  ซับไตเติลทีละคำ (ตัวขาว ขอบดำ คำสำคัญสีเหลือง)
js/audio.js      มิกซ์เสียงบรรยาย/เพลง/เสียงบรรยากาศ + ลดเสียงเพลงขณะมีบรรยาย
js/player.js     นาฬิกา 30 FPS, การเปลี่ยนฉาก, ปุ่มควบคุม, โหมดจับเวลา, บันทึก WebM
```

**ตัวละคร (สีและสัดส่วนเหมือนกันทุกฉาก):**
- ผู้เล่าเรื่องยุคปัจจุบัน: เสื้อยืดสีมัสตาร์ด กางเกงยีนส์ ผ้าขาวม้าพาดบ่า
- ชาวบ้านอีสานยุค 2500–2510: เสื้อม่อฮ่อม ผ้าขาวม้าคาดเอว หมวกสาน
- ผู้ร่วมขบวนการ (ตัวละครทั่วไป): ชุดเรียบง่ายสีเขียวหม่น หมวกผ้า สะพายเป้ ไม่มีอาวุธ
- เจ้าหน้าที่รัฐ: เครื่องแบบสีกากี หมวกทรงหม้อตาล ไม่มีเครื่องหมายสังกัดจริง

## ส่งออกเป็นวิดีโอ
- **⏺ บันทึกวิดีโอ (WebM):** ใช้ในตัวเล่นได้เลย (Chrome/Edge) บันทึกตามเวลาจริง
- **MP4 แบบตรงทุกเฟรม:** เรียก `window.renderAt(t)` ทีละเฟรมด้วย Playwright แล้วรวมกับเสียงด้วย ffmpeg
- `preview_silent.mp4` คือตัวอย่างที่ยังไม่มีเสียง และใช้เวลาประมาณ
