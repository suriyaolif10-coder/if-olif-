# WHAT IF HISTORY: ภูซาง หนองบัวลำภู — แนวการ์ตูนไทยหัวกลม

เวอร์ชันนี้ทำตามแนวภาพของวิดีโอตัวอย่าง (`video_20261122_204242.mp4`):
- **ตัวละคร:** หัวรูปไข่ เส้นขอบบางสีน้ำตาลเข้ม ลงสีแบนไม่มีแรเงา ตากลมมีจุดดำ (ข้างหนึ่งใหญ่กว่า) หูรูปตัว C จมูกเป็นเส้นตะขอเล็ก ๆ ปากอ้าเห็นลิ้นตอนพูด
- **ฉากหลัง:** เบลอแบบกล้องโฟกัสตื้น ส่วนตัวละครและข้อความคมชัด (แยกวาดเป็นเลเยอร์ใน `js/layers.js`)
- **ระยะใกล้:** มีหัวคนอยู่ใกล้กล้องแบบเบลอบังด้านหน้า ในฉากหมู่บ้าน ถนน และป่า
- **กล้อง:** เอียงเล็กน้อยและโยกช้า ๆ ทุกฉาก

## ปรับแต่ง
- ปรับความเบลอ มุมเอียง และหัวที่บังด้านหน้าของแต่ละฉากได้ที่ `SCENE_LOOK` ใน `js/layers.js`
- ปรับขนาดตัวละครทั้งเรื่องได้ที่ `CHAR_SCALE` (ตอนนี้ 1.45)

ใช้เสียงบรรยาย ElevenLabs (Helmut) และเวลาชุดเดียวกับฉบับ 3D
เนื้อหา ภาพถ่ายจริงพร้อมป้ายกำกับ และตอนจบ "ลีฟไง จะใครเล่า" เหมือนฉบับ 2D เดิม
