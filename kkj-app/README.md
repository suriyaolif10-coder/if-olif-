# เข็มทิศแก้หนี้ กข.คจ. · หมอแก้หนี้ by Olifsuriya

แอปตรวจสุขภาพกองทุน กข.คจ. 280K (อ.โนนสัง จ.หนองบัวลำภู และอำเภออื่นที่นำเข้า)

- `app.html` – ไฟล์เดียวพร้อมใช้ (ฉบับที่เผยแพร่บน claude.ai)
- `index.html` – ฉบับเว็บทั่วไป มี `<head>` และ OG meta สำหรับแชร์ LINE/Facebook
- `app.template.html` – ต้นฉบับก่อนฝังโลโก้และข้อมูลตั้งต้น
- `brand/` – โลโก้ (พื้นโปร่งใส / ขาว / ม่วง #FF00FF), วงกลมอย่างเดียว, OG image 1200×630

สูตร: รวมสุทธิ = เงินในบัญชี + เงินลูกหนี้ − เงินเสี่ยง, เงินเสี่ยง = เงินมีปัญหา + เงินเสียหาย, ≥ 280,000 = เงินครบ
