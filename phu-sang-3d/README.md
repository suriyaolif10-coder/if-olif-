# WHAT IF HISTORY: ภูซาง หนองบัวลำภู — ฉบับการ์ตูน 3 มิติ (Three.js)

วิดีโอแนวตั้ง 1080×1920, 30 FPS ยาวประมาณ 104 วินาที
- 9 ฉากตามเสียงบรรยาย ElevenLabs (97 วินาที)
- ตอนจบ "ลีฟไง จะใครเล่า" พร้อมปุ่มกดไลก์ กดแชร์ (5.5 วินาที)

## สิ่งที่เปลี่ยนจากฉบับ 2 มิติ
1. **แสงและเงา:**
   - ตัวละครและฉากเป็นโมเดล 3 มิติ แรเงาแบบการ์ตูน 3 ระดับ มีเส้นขอบดำรอบวัตถุ
   - แสงหลักจากดวงอาทิตย์ทอดเงาลงพื้น มีแสงจากท้องฟ้าช่วยเติม
   - โทนแสงต่างกันตามฉาก: แสงส้มยามเย็นในป่า แสงจันทร์สีฟ้ากับไฟอุ่นจากหน้าต่างสถานีตำรวจ แสงย้อนยามอาทิตย์ตก
2. **กล้องไม่เคยหยุด:** ทุกฉากใช้ฟังก์ชัน `mv()` ซึ่งรับประกันว่ากล้องมีความเร็วไม่เป็นศูนย์ตั้งแต่เฟรมแรกถึงเฟรมสุดท้าย
3. **กล้องเคลื่อนเข้าไปในฉากเพื่อให้เห็นรายละเอียด:**
   - บินผ่านยอดไม้ลงหุบเขาไปหาผู้เล่าเรื่อง
   - ดิ่งลงบนแผนที่ไปยังเขตงาน
   - เดินผ่านกลุ่มชาวบ้านไปจนเห็นวิทยุและหนังสือพิมพ์บนโต๊ะ
   - ตามรถบรรทุกไปหาคนงานที่ถือแบบแปลน
   - ค่อย ๆ เคลื่อนเข้าหาประตูสถานีตำรวจยามค่ำคืน
   - เลื่อนผ่านลำต้นไม้ไปพร้อมกับคนที่เดินในป่า
   - หมุนรอบสถูป
   - ยกกล้องขึ้นจากด้านหลังผู้เล่าเรื่องให้เห็นภูเขายามเย็น
4. **ไม่มีฉาก "คนรอบข้างหัวเราะ ตัวเอกร้องไห้"** ตามที่ตกลงกัน เพราะไม่เหมาะกับเนื้อหาที่มีผู้เสียชีวิตจริง

## เปิดใช้งาน
```bash
cd phu-sang-3d
python3 -m http.server 8000      # เปิด http://localhost:8000 (ต้องเปิดผ่านเว็บเซิร์ฟเวอร์)
```
ไลบรารี Three.js r160 เก็บไว้ใน `vendor/` แล้ว (สัญญาอนุญาต MIT ดูที่ `vendor/THREE-LICENSE`) จึงใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

## เวลา
- **จุดตัดฉาก:** `CUTS` ใน `js/scenes3d.js` หาจากช่วงหยุดใน `assets/audio/voiceover.mp3` (เติมเงียบนำหน้าไว้ 0.5 วินาที)
- **เวลาของแต่ละย่อหน้า:** อยู่ใน `js/narration.js` ส่วนเวลาของแต่ละคำในย่อหน้าเป็นการประมาณ ถ้าต้องการให้ตรงทีละคำ ใช้โหมดจับเวลา (ปุ่ม T) หรือนำเข้าไฟล์ JSON เวลาของคำ (📝)
- **ถ้าเปลี่ยนไฟล์เสียง:** ต้องแก้ทั้ง `CUTS` และเวลาใน `narration.js`

## ไฟล์
```
vendor/three.min.js   Three.js r160
js/three-kit.js       ระบบ 3D: วัสดุแรเงาการ์ตูน + เส้นขอบ, แสงและเงา, ตัวละคร 4 แบบพร้อมท่าทาง (ยืน, เดิน, ชี้, กอดอก, พูด, ขุดดิน, ถือแบบแปลน, ครุ่นคิด, กะพริบตา), ฉากประกอบ 3D
js/scenes3d.js        9 ฉาก 3D + ทางเดินกล้อง + ตอนจบ
js/assets2d.js        แผนที่อีสาน (ใช้วาดลายบนกระดาษแผนที่ใน 3D) + โลโก้
js/images.js          ช่องภาพถ่ายจริง (ภาพสถูปมีป้าย "ภาพถ่ายจริง")
js/narration.js       บทบรรยาย (ซับไตเติลตรงกับบททุกคำ) + เวลา
js/subtitles.js, js/audio.js, js/player.js   ซับไตเติลทีละคำ, มิกซ์เสียง, ตัวเล่น (ใช้ระบบเดียวกับฉบับ 2 มิติ)
```

## ความถูกต้องทางประวัติศาสตร์
ใช้หลักเดียวกับฉบับ 2 มิติ:
- ข้อความบนจอใช้เฉพาะข้อมูลที่อยู่ในบท
- ตำแหน่งบนแผนที่ติดป้าย "โดยประมาณ"
- ฉากปี 2509 แสดงเพียงเงาคนในระยะไกล ไม่มีอาวุธหรือภาพความรุนแรง
- ตัวละครทุกตัวเป็นตัวละครประกอบ
- ภาพถ่ายจริงมีป้ายกำกับทุกภาพ
- มีป้าย "ภาพจำลอง 3 มิติ · ไม่ใช่ภาพถ่ายจริง" ติดอยู่ทุกฉาก
